Este sitio no usa base de datos. Los proyectos viven en TypeScript y las entradas del blog en Markdown, cargadas en tiempo de compilación.

Elegí una sola columna de lectura, variables CSS para el tema y React Router para las URLs. Así el código se mantiene corto y es más fácil de defender en una exposición: cada carpeta tiene un propósito.

Si sustituyes los textos marcados con [Tu nombre], el mismo esqueleto sirve como portafolio real. Recuerda actualizar también los enlaces a GitHub, LinkedIn y el archivo `public/cv.pdf`.
